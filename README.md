# 🚀 Portfolio Personal — Cristian Gutiérrez

> **Ingeniero de Sistemas** · Desarrollo full-stack: interfaz, lógica de negocio y base de datos, con criterios de UX/UI.

Sitio web personal de una sola página (single-page), construido con tecnologías web nativas — sin frameworks, sin build step, listo para desplegar en cualquier lugar.

## 🛠️ Tecnologías del sitio

- **HTML5** semántico y accesible (`aria-*`, navegación por teclado)
- **CSS3** moderno: variables, grid, flexbox, `backdrop-filter`, animaciones con respeto a `prefers-reduced-motion`
- **JavaScript** vanilla: menú móvil, rol rotativo, animaciones con `IntersectionObserver`
- Identidad visual coherente con el branding de GitHub: `#0F172A` + acento `#38BDF8`
- 100% responsive (móvil, tablet, escritorio)

## 📁 Estructura

```
portfolio/
├── index.html      → Sitio completo (una sola página)
├── css/
│   └── style.css   → Estilos e identidad visual
├── js/
│   └── main.js     → Interacciones (menú, scroll reveal, rol rotativo)
└── README.md
```

> Las capturas y assets (banner, onda) se sirven desde el repositorio del perfil vía `raw.githubusercontent.com`, para mantener una única fuente de verdad de la identidad visual.

## 🌐 Despliegue

### Opción A · Vercel (recomendado)

1. Ve a [vercel.com/new](https://vercel.com/new)
2. Importa el repositorio `portfolio`
3. Vercel detecta que es un sitio estático — solo pulsa **Deploy**

### Opción B · GitHub Pages

1. En este repo: **Settings → Pages**
2. Source: **Deploy from a branch** → rama `main` → carpeta `/ (root)`
3. Guarda. El sitio quedará en `https://cristianagutierrezalc.github.io/portfolio/`
