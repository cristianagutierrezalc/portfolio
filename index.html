Proyecto destacado

GastroConnect ★ Sistema multi-sede

Sistema de gestión de restaurantes multi-sede: pedidos en tiempo real de todas las sedes, cupones, facturación e inventario, con una base de datos que lleva la lógica de negocio.

🖥️ Aplicación de escritorio

  • Java 17 + JavaFX 21, modular con Maven
  • Interfaz FXML + CSS, rediseñada desde Figma
  • Instalador Windows con jpackage
  • Tema claro y oscuro

🗄️ Base de datos

  • PostgreSQL en Supabase: 21 tablas y 10 vistas
  • Aislamiento por tenant y sede con RLS (74 políticas)
  • 39 funciones de negocio en PL/pgSQL
  • 168 pruebas end-to-end sobre la base real

Quién soy

Sobre mí

Me interesa convertir necesidades reales en productos digitales que funcionen de verdad: claros para el usuario y sostenibles en el tiempo. Normalmente cubro un proyecto completo, de la interfaz a la consulta SQL.

Mi formación principal es la Ingeniería de Sistemas (Universidad Popular del Cesar), complementada con certificaciones en ciberseguridad y bases de datos (Oracle: Database Foundations, SQL y PL/SQL).
